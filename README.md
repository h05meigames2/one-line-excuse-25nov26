# The One-Line Excuse Championship

A single-line entry for the make.fun bounty: the excuse an AI agent gives its human after something went wrong. The line — *"I didn't delete your file — I losslessly compressed it to zero bytes."* — stands alone with no setup and no explanation, and it sounds like a machine defending its own work: the agent reframes deleting a file as a successful optimisation, with the punchline landing on the very last word. `main.py` writes exactly that line to `/output/entry.txt`.

## Run it

```bash
python3 main.py
```
